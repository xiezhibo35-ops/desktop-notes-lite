# 安装说明（本机）

本目录是 [TODAYmiao/desktop-notes-lite](https://github.com/TODAYmiao/desktop-notes-lite) 的重做版 **v0.2.0**，
依赖已解包到 `.pylibs/`，无需联网即可运行。

- 源码：本仓库工作副本（基于上游 main `3a5311e` 重写）
- 运行环境：`D:\dev\python\python.exe`（Python 3.14.7）+ PySide6 6.12.0（Essentials）
- 依赖目录：`.pylibs/`（约 212 MB，直接从官方 wheel 解包，未走 pip）

## 怎么启动

| 文件 | 用途 |
| --- | --- |
| `启动便签.vbs` | 日常使用，双击启动，不带黑色控制台窗口 |
| `调试启动.bat` | 出问题时用，保留控制台并显示报错 |
| `start.vbs` | 仓库自带的入口：优先用 `.venv`，没有就用 PATH 里的 `pythonw.exe` |
| `main.py` | 真正的入口 |

v0.2 起，`main.py` 会自己把仓库目录和 `.pylibs` 加进 `sys.path`，所以**不再需要外部 PYTHONPATH** ——
这也是「开机自启」这次能真正生效的原因。单实例机制保证重复启动只会唤回已有窗口。

## 数据在哪

- 待办 / 重复规则 / 设置：`%APPDATA%\DesktopNotesLite\notes.json`（schema v2）
- 窗口位置与尺寸：`%APPDATA%\DesktopNotesLite\window-state.json`
- 崩溃栈：`%APPDATA%\DesktopNotesLite\crash.log`（若有）

首次用 v0.2 打开旧数据时，会先把原文件备份成 `notes.v1.bak.json` 再迁移；读到坏 JSON 会改名成
`notes.corrupt-<时间戳>.json` 留档，界面照常启动。删除这些文件即可恢复初始状态。程序不联网、不需要账号。

## 常用操作

- 记录一条：在底部输入框写 `评审材料 明天 @15:00 !!`，回车；任何地方按 `Ctrl+Alt+N` 也能跳过来
- 顺延：昨天没做完时，列表上方会出现「昨天还有 N 项未完成 · 搬到今天」
- 撤销：`Ctrl+Z`，或点删除后 toast 上的「撤销」
- 搜索：`Ctrl+F`，跨所有日期找
- 设置：右上角齿轮；主题、强调色、透明度、自动淡化、贴边吸附、开机自启都在这里

- 开机自启写的是 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\DesktopNotesLite`，命令是
  `"<pythonw>" "<本目录>\main.py"`。
- 桌面快捷方式：`C:\Users\22947\Desktop\桌面便签 Lite.lnk`。
- 测试：`python -m unittest discover -s tests -t .`（48 个用例）；截图：`python tools\smoke.py screenshots`。
